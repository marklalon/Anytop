# 动作纹理层：随机抖动类细节的生成与迁移

本文档说明为什么 glide 中翅膀/羽毛的局部高频抖动这类"噪音式"细节无法由 denoiser 直接生成，
以及把它从扩散模型中拆出来、作为程序化纹理层处理的方案。数值来自 2026-10-30 在
`zoo_locomotion_tiny_v56/v59/v60/v61` 与 `merged_all_v66` 上的探针测量。

## 速览

```text
训练 clip ──► 主体运动（原动作减去纹理残差）──► 扩散模型（现有 AnyTop）
         └─► 纹理残差（不规则、小幅、局部的高频）──► 统计量（每关节幅度 / 频谱形状 / 包络）
                                    │
                                    ▼
                       纹理统计预测（条件：物种 / label / 关节结构 / 参考动作）
                                    │
生成：扩散输出主体运动 + 按预测统计合成的有色噪声 ──► 最终动作
```

- denoiser 负责可预测的部分：姿态、节奏、肢体协调。
- 纹理层负责不可预测但统计上确定的部分：抖动的强弱、颜色、分布在哪些关节上。

## 1. 问题

`--action_label "fly, forward, glide"` 生成 PP_Eagle 时，即使训练集中有对应样本
（`PP_Eagle_FlyIdle`、`Dragon_WyvernFly2`），翅膀末端的细微颤抖也完全丢失。参考编码器路径和纯 label
路径共用同一个 denoiser，所以纯 label 路径生成不出来的细节，ref 路径也无法迁移过去。

GT 中的抖动特征：

| clip | 关节 | 主周期 | 幅度 |
|---|---|---|---|
| Dragon_WyvernFly2 | `BN_*Wing22Nub` / `BN_*Wing42Nub`（翼膜末端） | 3–4 帧 | 高频 RMS 约为该关节低频幅度的一半，约体长 0.5% |
| PP_Eagle_FlyIdle | `Wing_3/6/9/14/17_*`（羽毛） | 高频段（> 0.15 周/帧）占比 0.1–0.46 | 归一化空间各频段 RMS 0.04–0.06 |

抖动只出现在末端关节，往骨链根部一层就几乎消失。制作方式是在动作上叠加随机噪声。

## 2. 测量结论

探针在模型的归一化空间中测量：对 GT 加噪到 t，取单步 `pred_xstart`，统计翅膀关节运动幅度相对 GT 的比值（下称"增益"）。

### 2.1 去噪器在低噪声时也不保留这层抖动

| 模型 | clip | t=0 时翅膀增益 | t=0 时翅膀高频增益 | 从噪声生成的翅膀幅度 |
|---|---|---|---|---|
| merged_all_v66 | PP_Eagle_FlyIdle | 0.42 | 0.04 | 0.09× |
| merged_all_v66 | PP_Eagle_Flying（对照） | 1.01 | 0.82 | 0.99× |

同一组翅膀关节上，大幅扑翼能被完整复制，glide 抖动却被清掉。

### 2.2 增益由学到的上下文先验决定，与输入幅度无关

- Flying 的运动缩小到 0.15× 后仍被复制，增益约 1.0。
- FlyIdle 放大 3× 后仍被拒绝，增益 0.28。

去噪器在这里的表现近似 Wiener 收缩，增益约为 s²/(s²+σ²)。其中 s 是模型在该上下文里学到的先验幅度，
不是当前输入的幅度。v66 中 FlyIdle 翅膀高频段的实测增益远低于按 GT 幅度算出的值，说明模型学到的
"glide 翅膀高频方差"接近 0。

### 2.3 最小噪声与细节同量级

`--noise_schedule cosine --noise_schedule_shift 2 --diffusion_steps 100` 下，t=0 的 σ/√ᾱ 为 0.05，
与抖动幅度（0.04–0.06）相当。训练中没有任何一步能在"抖动高于噪声"的条件下观察到它。

### 2.4 tiny 10k 有绝对误差底

t=0 时各 clip 的 x0 绝对误差大致恒定（tiny 10k 约 0.08，v66 约 0.03–0.05），与运动幅度基本无关。
运动整体低于这个误差底的 clip 会被整段改写。所以 tiny 10k 不适合用来评估这一类小幅细节。

## 3. 已试过且无效的方向

| run | 改动（相对 v56） | 结果 |
|---|---|---|
| tiny_v59 | 给部分 glide clip 设 sample_weight 5–10 | 被加权的 clip 增益反而下降（如 DNL_Twohead_FlyStaticFwd 0.54→0.32）：模型更确信"glide 方差很小" |
| tiny_v60 | `--noise_schedule_shift_min 0.25`（低噪声段 σ_min 降到 0.006） | 探针增益小幅上升（glide 中位 0.52→0.62），生成无可见变化 |
| tiny_v61 | `--amp_norm_floor 0.05`（l_simple 按样本运动幅度归一化，所有步都加权） | glide 无可见效果；普通动作变扁平 |

有两个共同原因：

- **按 x₀ 幅度加权等价于重采样数据。** 权重依赖 x₀，而高噪声时 x_t 看不出幅度，所以最优预测会偏向
  小幅假设。效果上和提高这些 clip 的采样权重相同，改变的是学到的分布，而不是模型的分辨率。
  v61 中普通动作变扁平就是这个原因。`--amp_norm_snr_min`（默认 1）把加权限制在 SNR 足够高、
  幅度能从 x_t 看出来的步上，其余步权重为 1。
- **每个样本一个标量权重，不改变样本内部的相对比重。** 同一个 glide 样本里，抖动仍是误差中最小的一项。

## 4. 为什么和 denoiser 冲突

理论上，扩散模型可以生成随机纹理：采样器每步注入新噪声，在 σ 与纹理幅度 s 相当的步里，
模型按 s²/(s²+σ²) 保留一部分残余噪声，它就成为最终样本里的纹理。抖动不需要模型"创造"，只需要模型"不去除"。

对随机抖动，这一机制在实践中几乎失效：

1. **统计上与扩散噪声几乎不可分。** 叠加的随机抖动逐帧、逐关节看，和扩散噪声是同一类东西，而去噪器的训练目标正是去掉它。
   唯一的区分依据是这些关节的总方差比 σ² 多出 s²，在 σ≫s 时这个差别极弱。
2. **可区分的步太少。** σ_min≈s，而 `sigma_small` 下最后一步不注入噪声，输出就是 t=0 的 x₀ 预测，其高频增益接近 0。
3. **先验接近 0。** 全库只有少数 clip 带这种纹理，网络本身也偏向平滑函数。
4. **数据里的抖动已被削弱。** 长于窗口的 clip 被重采样压进窗口（FlyIdle 101→60 帧），抖动周期被推向 Nyquist，插值本身就是低通。

**结论：抖动的具体波形不可预测，去噪器就不该负责它。但抖动的统计量是确定、可预测的，适合用回归直接学习。**

## 5. 方案

### 5.1 分解

纹理与正常高频扑翼（Giantbee 等，周期 2–4 帧）在频率上重叠，单靠截止频率分不开。
分解改为按"能否预测"自动判定，不做人工标注。

**在重采样进窗口之前、按原始帧率分解。** 窗口重采样本身是低通（§4 第 4 条），在窗口数据上测到的抖动已被削弱。

对每个 clip 的每个关节：

1. **候选高频**：局部旋转减去其平滑结果，得到高频候选分量。
2. **去掉规律部分**：从候选分量中拟合并减去周期成分。loop clip 用整段的周期平均（按 loop 长度折叠）；
   非 loop clip 由自相关估计主周期后做谐波拟合。剩下的不规则部分是纹理残差的候选。
3. **判定是否为纹理**，同时满足才算：
   - **不规则**：候选分量中周期成分占比低，自相关在主周期处没有明显峰。
   - **小幅**：残差的旋转角幅度远小于该关节主体运动的幅度，且绝对角度小。
   - **局部**：沿骨链向根部迅速衰减，与父关节的残差相关性弱。

   Giantbee 式的扑翼周期性强、幅度大、整条翅链一起动，三条都不满足，会被排除。
4. 判定为纹理的关节，残差从动作中减去，得到主体运动；其他关节的残差记为 0，动作原样保留。

三条判据的阈值由 §6.1 的全库普查确定。

### 5.2 纹理统计量

统计量一律在**每关节局部旋转角**（残差旋转的 axis-angle）上测量。旋转角与骨架尺度无关，不需要按链长归一化。
从残差中为每个关节提取：

| 统计量 | 含义 |
|---|---|
| 有无纹理 | §5.1 的判定结果 |
| 幅度 | 残差旋转角的 RMS |
| 频谱形状 | 残差功率谱的少量参数（如带通中心与带宽，或若干频段能量），频率用物理时间单位（周/秒） |
| 包络 | 幅度随时间的变化（恒定 / 渐强 / 随主体运动调制） |
| 关节间相关 | 相邻关节、左右对称关节的残差是否相关 |

具体选哪些统计量，取决于 §6.1 的数据分析结果。

### 5.3 统计量的来源

按数据量和需求由简到繁：

1. **查表或规则**：按物种 + label 记录 GT 统计量，生成时直接取用。适合当前这种样本极少的情况。
2. **从参考动作确定性迁移**：有 ref 时，对参考 clip 按 §5.1 测出每关节统计量，再按结构分组搬到目标骨架。
   分组键为左右侧（`joint_side_labels`）、链角色（翅、尾、腿等）、链上的归一化深度（末端为 1），
   目标关节取同组参考关节的统计量。迁移的是统计量而不是波形，旋转角也无需尺度换算，对骨架差异不敏感。
   cond 里没有现成的链角色字段，需要从 cross-limb 使用的肢体划分或关节名嵌入派生。
   不需要训练，也不依赖 retarget 的关节映射。
3. **独立纹理头**：一个小网络，输入是冻结的主干条件 embedding（物种、label、关节名嵌入、结构特征），
   输出每个关节的统计量。不动主干，训练快，用来迭代 §5.2 的统计量定义和 §5.4 的合成效果。
   - 回归同样会收缩到条件均值：同一物种 + label 下有的 clip 带纹理、有的不带时，会学成处处一点弱抖动。
     因此输出拆成**有纹理的概率**与**有纹理时的幅度和谱形**，推理时先按概率采样是否叠加。
4. **主干辅助头**：统计量定义确定后，把纹理头接到主干的每关节 token 上联合训练，
   总 loss 为扩散 loss + λ · 统计量回归 loss。
   - 输入读条件侧 token，不依赖 x_t，推理时一次前向即可。若 §6.1 发现包络随主体运动调制，再加读去噪器表征。
   - 输出形式同第 3 条；对有纹理样本加权，避免学成恒为 0。
   - 用头输入处的 stop-grad 做对照，确认辅助 loss 不伤害主干的生成质量。
   - 需要重训主干，只在 §5.5 的去纹理训练另有收益时合并做。
   - 第 2 条的确定性迁移不够用时，才考虑让头读 ref z。encoder 目前只受 denoiser loss 训练，
     而 denoiser 忽略纹理，z 未必编码这一量级的细节；要让 z 带上纹理，辅助 loss 的梯度必须进入 encoder，
     与 stop-grad 对照互斥。

第 3、4 条是否进行，由 §6.1 普查出的带纹理 clip 数量和物种覆盖决定：正样本太少时，学到的头等价于查表，
不能泛化到没有纹理样本的物种。

### 5.4 合成

生成时，扩散模型输出主体运动。纹理层只对判定为有纹理的关节，按统计量合成有色噪声
（白噪声经过与频谱形状匹配的滤波，再乘以包络），作为 axis-angle 扰动复合到局部旋转上，最后再走现有的导出流程。
- 噪声按输出动作的物理帧率和时长合成，频谱从周/秒换算到输出帧。
- loop 动作的纹理要做成循环的，例如在频域按整周期合成。

### 5.5 训练数据

可以让主模型改学去掉纹理的主体运动，减少它对这类成分的困惑。这一项是可选的：需要先确认去纹理后
其他动作的质量不下降，并单独做一次 A/B。

ref encoder 的输入仍用带纹理的原始 clip，只有 denoiser 的目标换成主体运动。

## 6. 验证计划

### 6.1 数据分析（不训练）

**全库普查**：对所有 clip 跑 §5.1 的分解，输出每个 clip、每个关节的三条判据得分与判定结果。

- 用已知样本校准阈值：`PP_Eagle_FlyIdle`、`Dragon_WyvernFly2` 必须判为有纹理；Giantbee 等高频扑翼、
  `PP_Eagle_Flying` 等正常扑翼必须判为无纹理，且主体运动不被改动。
- 统计判为有纹理的 clip 数量、物种和 label 分布，渲染 GIF 抽查判定结果。这个数量决定是否进入 §5.3 第 3、4 条。

**噪声模型**：在判为有纹理的 clip 上，确认制作时用的噪声模型：

- 残差的自相关和功率谱：是白噪声、平滑噪声，还是窄带？
- 关节之间、左右之间是否相关？
- 幅度包络是否恒定？

### 6.2 后处理原型（不训练）

对 v66 的 glide 生成结果，按 GT 统计量叠加有色噪声，人工比较观感是否接近原始 glide。
这一步决定方案是否可行，以及 §5.2 的统计量是否足够。

量化指标：

- 叠加后，末端关节残差的幅度与谱形和 GT 统计量的差距。
- 无纹理对照：对无纹理 clip 的生成结果走同一流程，应不叠加任何纹理，观感不变。

### 6.3 接入

- 原型可行后，先用查表方式接入 `sample/generate.py`，作为生成后处理的可选开关。
- ref 路径接入确定性迁移（§5.3 第 2 条），用 Eagle←Wyvern 等跨骨架组合检查分组是否合理。
- 普查出的正样本足够时，训练独立纹理头（§5.3 第 3 条），调通统计量定义与合成。
- 定型后再考虑主干辅助头（§5.3 第 4 条），对比独立头与辅助头在无纹理样本物种上的泛化。

## 7. 未决问题

- §5.1 三条判据的具体度量与阈值，能否在不误伤正常高频扑翼的前提下检出所有纹理。
- 链角色分组在形态差异大的骨架间（如鸟翅与翼膜、羽毛关节与翼骨）是否对得上。
- 叠加旋转纹理后，脚部接触等约束是否需要修正（目前纹理只出现在翅膀末端，暂不涉及）。
- 纹理与主体运动是否有关联（例如抖动强度随扑翼相位或速度变化）。如果有，包络需要以主体运动为条件。
- ref z 是否编码了纹理信息；只在确定性迁移不够用时才需要回答。
