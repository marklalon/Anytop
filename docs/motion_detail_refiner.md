# 冻结主干后的动作细节 Refiner

更新：2026-10-31。**状态：设计方案，尚未实现 refiner 网络、训练入口或推理开关。** 原先在主干训练中追加完整采样统计损失的方案已废弃，相关代码、参数、专用测试和方案文档已清理。主干恢复常规训练流程；本文件是后续细节注入方案的依据。

## 1. 目标和边界

先按现有方式训练主干，确认其姿态、根运动、普通动作振幅和节律合格，再冻结主干，独立训练一个小型 refiner，为主干生成结果补充局部高频细节。

两阶段使用独立参数、优化器和 checkpoint。主干架构、常规加噪训练、损失、EMA 和采样日程不因 refiner 而改变。refiner 的统计损失只更新 refiner，不能通过主干回传。

refiner 学习“生成的细节统计像 GT”，不学习“与随机抽到的 GT 逐帧相等”。不使用 GT 波形重建 `l_simple`，不要求随机细节的相位对齐。

**主体保持是前提，不是 refiner 的修复任务。** 如果冻结输入已经丢失普通拍翼振幅，refiner 不能在维持主体不变的同时恢复拍翼。v68 的退化权重不应直接视为合格底座；主干候选需先独立验收。历史 v67 定向实验的细节指标也不是新方案的效果保证。

## 2. 为什么采用独立模型

旧方案的统计梯度会更新共享去噪器，细节校准可能改写所有 timestep 的生成行为。扩大到全库后，每条件统计更新稀疏，损失尺度也没有同步适配，出现了细节未恢复而主体运动变弱的问题。调查证据保存在 [v68 评估记录](../outputs/v68_regression_investigation/evaluation.md)；各因素尚未经过完整因果消融。

冻结主干使其输出分布稳定，便于缓存、反复训练和逐条件对照。它保护主干权重，但不自动保证 refiner 的输出安全；后者仍需结构约束和最终动作检查。

## 3. 数据流与网络接口

```text
骨架 + 动作/速度/loop 条件 + 主干随机种子
                    ↓
            已训练主干，eval / frozen
                    ↓
                基础动作 x_base
                    ↓
小型 refiner(x_base, 骨架, 条件, 独立时序噪声 z)
                    ↓
       局部旋转残差 → 频带/幅度限制 → 合成
                    ↓
                最终动作 x_out
```

第一版采用一次前向生成整段残差的小型时序网络。复用骨架拓扑、有效关节/帧 mask、已有语义条件和物理表示工具，不复制主干，不新增主干输出头，也不先引入第二套多步扩散。

输入包括：

- 基础动作的局部旋转及其时间变化；根运动只作为上下文。
- parent、rest offsets、已有结构/关节条件，保证不同骨架下关节身份明确。
- 动作条件、真实时间尺度、输出长度和 loop 标记，避免相似姿态下混淆应有细节。
- 与主干随机种子分离的时序噪声。它应能表达连续细节，而不是每帧独立白噪声。

输出为每个有效非根关节每帧的三维小角度旋转残差；不输出整段新姿态，不预测根轨迹。网络支持变长骨架和窗口，不写 Eagle、glide 或关节名称特例。

噪声输入不代表已经获得多样性，必须检查固定基础动作、改变细节种子时输出确实变化。底座不同、细节种子相同也不能强制使用同一纹理。

## 4. 残差限制和主体保持

设基础局部旋转为 `R_base`，refiner 输出切空间向量 `u`。推荐合成形式为：

```text
delta = 有效关节 mask × 幅度控制 × 高频投影(u)
R_out = R_base × Exp(alpha × delta)
root_out = root_base
```

`delta` 使用弧度，`alpha` 为细节强度；参考频谱可用角度统计，但单位换算必须显式一致。旋转在合法 SO(3) 上合成，不直接向冗余 6D 通道添加抖动。

第一版以现有高频诊断的 0.15 周/训练帧为起始分界候选，而非所有动作的天然真理。必须记录帧率/时间映射；改变输出长度、resample speed 或采样时钟时，按实际时间映射频率。不能对同一原动作重采样后仍机械使用相同周/输出帧阈值。动作的主体频段若与拟注入频段重叠，应提高保护范围或拒绝注入，不能靠物种标签猜测。

闭合窗口使用周期一致的滤波和噪声；开放窗口采用 DCT 或明确边界处理，不能把首尾强行连接。padding 不进入滤波、统计或归一化。

幅度上限由训练数据和验证结果校准；所有条件需能输出接近零的残差。若需要硬上限，可在高通后用每关节、整窗口统一的缩放控制最大幅度。逐帧截断/非线性门控可能重新引入低频，不能把它放在滤波后而忽略泄漏。

**高通只能限制残差坐标，不严格保证最终动作低频不变。** SO(3) 合成和层级 FK 都是非线性的，需要对合成后的局部/结构参考系旋转、主体位置、动作节律重新检查。保持损失以本次 `x_base.detach()` 为唯一主体参照，不使用 GT 的随机低频轨迹，也不使用相邻去噪步作为代理。

`alpha=0` 或关闭 refiner 时直接返回原基础动作，保证恒等路径，不经重新解码/FK 后近似返回。

## 5. 位置、旋转与导出的一致性

现有动作包含位置与旋转冗余通道。只改变旋转却保留不匹配的位置，可能使不同导出/渲染路径表现不同；简单把全体位置替换为 FK 又可能改变基础动作。

第一版需在实现前固定合成契约，并做零残差往返检查：

- 以局部旋转和根轨迹作为细节的权威输入，使用现有 rest offsets 与骨架层级传播细节位移。
- 可评估“基础位置 + FK(细化旋转) − FK(基础旋转)”作为保持基础位置误差的适配方式；它在零残差时保持原位置，但不能宣称能修复基础几何或保证严格骨长。
- 若采用旋转/FK 统一重建位置，必须先证明基础动作的该往返误差在验收容差内；否则不能把重建引入的主体变化归因于细节。
- 根轨迹不参与重新拟合。蒙皮、骨架显示、NPY/BVH/GLB 输出应消费同一合成结果。

不能同时承诺“保留本来不自洽的基础位置”和“最终位置完全符合旋转 FK”。底座几何质量不合格时，应先处理底座或明确拒绝作为训练基础。

## 6. 训练样本、缓存和覆盖预算

训练输入必须包含**冻结主干真实生成的动作**，不能只用 GT 低通结果代替，否则 refiner 会在真实推理输入上面临分布差异。GT 只提供同条件的经验细节目标，无需逐帧配对。

优先提前生成多种子基础动作缓存。缓存至少记录：主干 checkpoint/权重类型与指纹、cond/表示版本、骨架、动作条件、帧率与时间映射、输出长度、loop、速度、采样方法/步数/CFG、主干种子。refiner 噪声训练时重新采样。

主干冻结后，缓存不存在随权重更新而陈旧的问题；但覆盖不足和过拟合固定缓存仍会发生。保留未见主干种子、未见细节种子做验证；更换主干或采样契约后需重新验收，必要时重建缓存。

只使用训练 split 生成统计目标；验证来源不进入训练统计或归一化尺度。没有高频标记也不代表目标一定无细节，高频元信息用于来源选择和已有时间处理，不能作为直接放大开关。

每个统计比较小组保持骨架身份、条件和时间设置一致，不把不同动作/物种混成一个 MMD 分布。可在一次优化中累积多个条件小组，但分别计算目标。

用条件组覆盖和每组更新次数制定预算，记录实际抽样次数，而非只规定全局 step/间隔。同 clip 多个窗口不是独立 clip，batch 中重复窗口不能证明数据丰富或生成多样性。

## 7. 训练目标

```text
L = lambda_stat × L_detail_statistics(x_out, GT)
  + lambda_keep × L_body_preservation(x_out, x_base)
  + lambda_geo  × L_geometry(x_out, x_base, rig)
  + lambda_reg  × L_residual_budget(delta)
```

### 细节统计

比较 **最终输出** 与 GT 的细节统计，不要求残差本身匹配 GT 高频。基础动作可能已经含有部分细节，直接匹配残差会重复注入。

首版候选特征包括逐关节分频带幅度、旋转轴/方向统计、局部包络分位数及邻接关节相干性；进一步检查细节包络与主体动作阶段/速度的关系。总能量相同不代表抖动方向、关节关系或随动作变化的强弱合理。

使用条件内的 MMD/矩匹配与明确的幅度项；特征按训练集尺度归一化，设置稳定的分母下限并限制极端尺度。不能直接照搬旧实验的 1/2/4 等权重。按条件、关节组、频带查看误差和梯度，避免近静止关节的大量惩罚压过真正有细节的部分。

统计目标不能单独保证多样性和完整动作分布正确。只有一条 GT 的动作不能据此宣称学到了真实细节分布。

### 主体保持

保护最终输出相对基础动作的低频运动、平均姿态、根轨迹、主体关节位置、节律和幅度；在物理旋转/结构参考系中检查，不仅比较标准化冗余坐标。根轨迹由合成结构固定，其余项目使用损失与独立评估共同保护。

不对齐 GT 低频波形，不增加恢复普通拍翼的目标。干净/弱细节条件也必须验收，不能只训练高频正例。

### 几何、边界与残差预算

检查输出位置与旋转、骨长、loop seam/开放端点，限制相对底座的几何退化。残差幅度正则是防止异常注入的辅助项，需与统计目标平衡，不能把接近零输出自动视为优解。

RMS 类目标在严格零信号处可能没有恢复梯度。refiner 不能只依靠完全为零的残差初始化等待统计 loss 自发启动；采用可控小非零初始化，并测试从弱输出恢复幅度的参数梯度。主体安全由幅度限制和验收保证。

## 8. 训练和推理流程

1. 正常训练并选择底座；单独确认普通动作、参考条件和骨架泛化合格。
2. 冻结底座及其条件模块，选择固定在线或 EMA 权重；建立可复现的多种子缓存。
3. 独立训练 refiner，只更新其参数；记录每条件覆盖、各损失和裁剪前梯度。
4. 用未见主干种子和细节种子做完整推理，检查主体保持、细节、几何和多样性。
5. 推理先正常生成一次，再运行 refiner 一次。保存底座结果、细化结果及可重现种子，便于关闭和对比。

refiner checkpoint 单独保存架构、表示/条件契约、频带/时间规则、归一化统计和兼容底座信息。主干 checkpoint 不嵌入 refiner 权重；更换主干后不得未经验证自动复用。

本方案新增一次小模型前向，因此推理有额外开销。缓存后的训练不必每次执行主干去噪链，也不必保留主干计算图；具体速度与显存收益需实现后测量。

## 9. 首轮验收与后续实现顺序

先做有限条件能力验证，但实现不得依赖物种/标签/关节名特例。通过后再扩大来源，并同步增加每条件预算与验证覆盖。

| 验收项 | 必须验证的行为 |
|---|---|
| 冻结与隔离 | 主干参数/缓冲区不被修改，梯度和优化器只覆盖 refiner |
| 恒等路径 | 关闭或 alpha=0 返回原动作；旋转/位置适配零残差检查通过 |
| 主体保护 | 最终动作低频、姿态、根路径和普通拍翼幅度不超过预定退化容差 |
| 有效细节 | 新种子上频带、轴方向、包络、关节关系接近 GT，且人工可见 |
| 干净负例 | 不应抖动的条件不出现新增噪声 |
| 多样性 | 固定基础动作改变细节种子时有合理变化，不是固定模板或随机白噪声 |
| 几何与边界 | 骨长、自洽、蒙皮及 loop/开放边界均合格 |
| 时间与骨架 | 变长、重采样、不同拓扑和 padding 不改变频率/身份含义 |

容差和参考统计在评估前固定并随报告保存，不在看到候选结果后调整。先比较底座与 refiner；必要时加入简单随机带限残差对照，确认网络优于任意加噪。

后续实现依次为表示/合成与边界工具、统计特征及梯度检查、缓存生成与契约验证、小型网络和独立训练入口、可选推理集成。当前不创建占位 CLI、不提供虚构训练命令，也不宣称已有可用 refiner。
