# 动作细节保留：单主干、末步统计匹配

更新：2026-10-31。**状态：新方案草案，尚未实现或训练。** 旧的高频 MSE 加权实现、实验入口、评估脚本和测试已清理，仅保留本文方案及实验结论；已有训练权重和生成结果保留。

## 1. 为什么换方向

高频权重 16 从 v67 10k 续训到 15k 后，Eagle glide 的羽毛颤动没有恢复：默认生成的羽毛高频 RMS 从 0.0584° 降至 0.0363°。原生 60 帧下也下降，只有对应 GT 窗口幅度的约 1.3%。

带噪 GT 重建同样失败：FlyIdle 高频相关增益为 0.0414→0.0257，普通 Flying 则为 0.6718→0.7699。提高重建权重没有解决目标细节问题。详细记录见 [15k 评估](../outputs/hf_v67_eval_15k/evaluation.md)。

新方案改为：**只要求最终生成动作中的局部细节具有相似的频谱和强度变化，不要求复现 GT 的具体波形。**

## 2. 一个主干，两个训练分支

所有 timestep 共用同一个 denoiser θ，主干参数正常更新，不冻结 v67，也不复制第二个网络。可以从头训练，也可以从现有 checkpoint 继续。

常规分支负责学习整体动作；额外的生成分支只在最终输出上施加统计损失：

```text
常规分支：GT → 加噪 → 同一主干 θ → 去噪重建目标

生成分支：随机噪声 + 原有条件
                 ↓
          同一主干 θ：t=99…1
          本次不记录梯度
                 ↓
          末步输入 u.detach()
                 ↓
          同一主干 θ：t=0
          本次记录梯度
                 ↓
          最终动作 y → 统计 loss
```

**不记录前 99 步的梯度，不等于冻结这些步骤的网络。** 参数 θ 仍由常规分支和末步分支共同更新；这里只截断生成分支的反向传播，降低显存成本。

统计分支的输入必须来自当前模型的真实采样，而不是直接用加噪 GT 的 t=0 输入代替。后者仍然只是单步重建代理，不能当成最终生成结果的分布。

推理使用同一套权重完成全部 100 步，输入条件不变。共享参数意味着末步梯度也可能改变其它 timestep 的行为，不能保证影响只限于最后一步，仍需检查普通动作。

## 3. 统计 loss 看什么

先只针对 Eagle glide 做能力验证，不承诺泛化到全库。对 GT 和最终生成结果使用同一套局部旋转统计，保留关节身份，不把所有关节混成一个能量值。

首版每个关节只提取四个数：

| 统计量 | 作用 |
|---|---|
| 0.15–0.25 周/帧的 RMS 幅度 | 约束较慢的高频变化 |
| 0.25–0.5 周/帧的 RMS 幅度 | 约束更快的细节，区分粗细 |
| 高频短窗 RMS 包络的 25% 分位数 | 约束较平静时有多强 |
| 高频短窗 RMS 包络的 75% 分位数 | 约束较活跃时有多强 |

不比较复数频谱系数或相位，也不逐帧对齐包络。短窗先用 8 帧，覆盖已观察到的 3–4 帧颤动周期的约两个周期；这是实验起点，不是已验证的最优值。

统计基于合法局部旋转，避免模型仅在冗余 6D 坐标中增加能量。首版不增加“高频且小幅”的自动分类器：对每个有效关节使用同样的统计定义，GT 接近零的关节也保留，用来约束误加抖动。

将每个样本所有关节的统计量拼成向量 φ(y)，使用 MMD 比较一批生成统计与一批 GT 统计：

\[
L_{stat}=\operatorname{MMD}^2\bigl(\{\phi(y_i)\},\{\phi(x_j^{GT})\}\bigr)
\]

生成样本与 GT 不需要一一配对。GT 的不同原速窗口可以作为经验参考，但重叠窗口不是独立的新 clip，不能据此声称解决了数据稀缺。

统计必须在同物种、同动作条件及匹配时间设置下比较。不能把干净和带颤动的不同条件混成一个全局分布，再让模型自己猜应该给谁抖。

## 4. 怎样安排损失，避免目标互相拉扯

首轮仅对已有条件中的 Eagle glide 开启末步高频统计替换，不做纹理分类器。损失分工如下：

| 情况 | 训练目标 |
|---|---|
| 常规分支，t>0 | 保留原有完整去噪 MSE 和辅助损失 |
| 常规分支，t=0，目标 Eagle glide | 保留低频 GT 重建，取消高频逐帧 GT MSE |
| 常规分支，其它条件的 t=0 | 沿用原有去噪目标，保护普通动作与干净负例 |
| 生成分支，目标 Eagle glide 的最终输出 | 统计匹配，加末步主体一致性约束 |

不能一边要求目标高频统计恢复，一边在同一末步继续用 GT 波形 MSE 把它拉向条件均值。对目标条件的 t=0，现有辅助损失中要求逐帧贴合 GT 高频的部分也应关闭；骨架自一致性则应从输出自身的 FK/骨长关系构造，不要求匹配 GT 随机波形。

整体形式是：

\[
L=L_{常规}+\lambda_{stat}L_{stat}+\lambda_{preserve}L_{preserve}
\]

生成分支的 `L_preserve` 比较末步输出的低频部分与**前一步 t=1 的 pred_xstart 的低频部分**。后者来自同一网络，取 stop-gradient，作为末步不要突然改写主体运动的参照。

这个参照不是冻结的 v67，也不是同一个 t=0 输出的 detach 副本。若比较 y 与同参数、同输入下的 y.detach()，损失恒为零，不能提供保护。

不要把真实采样生成的动作与某条随机抽到的 GT 做低频逐帧 MSE：二者的相位和具体主体运动未必一致。GT 的低频监督由常规加噪训练分支承担。

首版不同时引入新网络头、噪声 schedule、可学习滤波器或自动 loss 权重。各 λ 需通过小实验的损失尺度、梯度和低频偏移确定，不直接沿用旧方案的权重 16。

骨长、位置/旋转自洽、近端关节抖动和实际渲染仍需检查。不能把旧的逐帧 GT 几何重建项原样加进统计分支，否则它可能重新要求随机残差逐帧对齐。若出现骨架失真，本版判为失败，先分析原因，不把统计 loss 降低当作成功。

## 5. 为什么不在所有 timestep 上替换 MSE

中间步骤的 pred_xstart 在标准训练下是条件均值估计，不是一个必须具有完整 GT 方差的样本。高噪声时强迫它拥有完整颤动能量，会改变反向均值的含义，效果可能在后续采样中消失或变成伪抖动。

本方案直接约束真正的最终输出，允许主干在末步利用 u 中的随机性生成不同波形。它不需要知道“GT 当时随机出了哪段波形”。这改变了任务，而不是试图靠更大权重恢复已经丢失的信息。

但这也不是标准去噪目标的等价改写，而是对有限步采样器的生成结果做校准；不能宣称仍有原始扩散训练的全部理论保证。

## 6. 先做便宜的验证

先用常规去噪训练作为 warm-up，等模型已经能生成基本动作，再逐步启用末步统计分支。主干始终参与训练；warm-up 是避免用初期近乎随机的采样结果学习细节统计，不是冻结 v67。何时开启由生成检查决定，不预先声称某个固定步数一定足够。

统计分支不必每个更新步骤都执行。首版低频率、以小批量从当前模型生成 u，前 99 步不记录梯度，最后一步回传。显存开销主要是一次主干反传，但仍需支付前 99 步的前向计算，训练不会与普通单步去噪一样便宜。

由于 θ 持续更新，u 的分布也在变化，不能长期复用 v67 的固定末步缓存。若后续需要缓存提速，必须短期刷新并记录陈旧程度；首版不依赖长期缓存。训练与验证使用不同种子。

按顺序验收：

1. **损失函数检查**：允许相位变化；惩罚错误幅度、错误频带比例和干净目标中的额外能量；在当前极小幅度附近仍有有效梯度。
2. **短程能力检查**：统计差距下降，低频主体不明显偏移；普通动作与干净负例没有额外抖动。
3. **新种子完整生成**：从纯噪声开始，用同一套最终权重走完全部步骤，不只评估训练中的末步输入。
4. **多样性和视觉检查**：同一条件下多次生成的细节波形应有变化，同时频谱、包络和关节分布类似。固定重复一段波形不算成功。

首轮固定原生 60 帧，并明确 loop/tempo 与目标窗口的关系，避免同时混入导出问题。随后必须单独通过原命令的默认 106 帧、自动 loop 设置；60 帧成功不等于用户实际生成命令成功。频率统计需按同一输出时钟换算，超出原生窗口可表示频率的细节不承诺恢复。

先做小规模通路和新种子检查，再决定是否值得长训；不预设再追加 5000 步。网络训练由用户运行。

## 7. 已做的损失函数检查

使用真实 FlyIdle 60 帧窗口的局部旋转高频残差，只做 CPU 数学检查，没有训练模型：

| 检查 | 结果 |
|---|---|
| 将同一高频波形循环移位 | 平均波形 MSE 约 0.8613 deg²；统计 loss 为 0 |
| 波形幅度缩到 GT 的 1.3% | 统计 loss 的梯度指向增加幅度；相位平均 MSE 的梯度指向继续减小幅度 |
| 删除全部高频 | 统计 loss 非零 |
| 干净参考中加入细节 | 统计 loss 非零 |
| 每次重复同一段 GT 波形 | 统计 loss 仍为 0，暴露出必须另行检查的模式坍缩问题 |

本次检查使用每关节两个频带幅度、8 帧循环 RMS 包络的两个分位数，以及固定尺度的 RBF-MMD。循环包络只用于使循环移位测试严格成立；非 loop 训练需要按有效窗口处理边界，不能直接照搬循环拓扑。

结果见 `outputs/hf_stat_loss_sanity/results.json`。它只验证了目标函数的部分性质，**不是新方案已能改善生成的证据**。同样，MMD 只匹配所选特征的分布，不能保证完整动作分布正确，也不能凭空学会没有数据支持的使用场景。

## 8. 理论与方法依据

- [Generative Moment Matching Networks](https://arxiv.org/abs/1502.02761)：用 MMD 训练生成器进行分布匹配，支持“不要求逐样本波形配对”的目标形式。
- [MMD-DDM](https://arxiv.org/abs/2301.07969)：针对有限步扩散生成结果使用 MMD 微调，支持把分布匹配放在采样结果上。
- [DRaFT / DRaFT-K](https://arxiv.org/abs/2309.17400)：从最终生成结果反传可微目标，并研究仅通过最后 K 步回传的方法。

这些研究支持方法路线，不证明它对当前骨架数据有效。“单主干常规去噪训练＋末步统计分支、截断采样反传、局部旋转统计与主体一致性”的组合，是本项目待验证的工程方案。第 7 节的数学检查只涉及统计目标本身，并未验证这种联合训练。
