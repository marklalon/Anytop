# Checkpoint 人工评审报告

`eval/eval_checkpoint.py` 在评测结束时生成交互报告，报告目录包含：

- `eval_report.html`：任务列表、动作网格、人工评分面板与 Summary。
- `eval_report.json`：任务清单、动作相对路径、自动评分统计及任务版本。
- `report_assets/`：页面代码和本地 Three.js，无需连接 CDN。
- `serve_report.py`：仅依赖 Python 3.10+ 标准库的本地服务。
- `human_scores.json`：首次人工评分后创建，记录任务分数、任务版本和保存时间。

评测成功后会自动在后台启动独立的本地服务，选择空闲端口，并在服务就绪后打开浏览器。评测进程可以正常退出，评分服务继续运行；服务日志保存在报告目录的 `serve_report.log`。传入 `--no_review`（或 `--no-review`）可关闭自动启动和打开页面，适合批量评测。评测失败时不启动预览。

之后也可以在报告目录手动运行：

```powershell
python serve_report.py --open
```

或从项目目录指定报告目录：

```powershell
python Anytop/eval/checkpoint_report.py <报告目录> --open
```

默认地址为 `http://127.0.0.1:8766/`；`--port 8767` 指定其他端口，`--port 0` 自动选择空闲端口。双击 HTML 时页面会显示启动服务的提示。

左侧搜索支持任务名及 command 中的多个关键词；选中任务后，中间两列显示全部生成的 BVH 动作，首屏为 2×2，更多动作向下滚动。动作视图内不显示按钮或信息，帧数和 FPS 统一显示在任务标题栏。在一个视图中调整相机会同步到所有视图（保持相同的朝向与相对缩放），操作与 `joint_names.html` 相同：中键旋转、右键或 Shift+中键平移、滚轮缩放，不启用惯性。底部播放、逐帧、速度和时间轴控制全部动作。不同长度的动作按相同秒数播放，短动作在末帧等待，最长动作结束时一起循环。

按 ↑ / ↓ 切换当前搜索结果内的任务（搜索框获得焦点时也可使用）；小键盘 1–9 直接给当前任务评分，支持 Num Lock 关闭时使用，在文本输入框中不触发评分。

右侧评分按钮按小键盘布局排列（7 8 9 / 4 5 6 / 1 2 3），点击 1–9 分即保存，左侧同步显示分数和边框颜色：1–2 红、3–4 橙、5–6 黄、7–9 绿，未评分为灰色。可以改分或清除。Summary 统计整个报告，包含原有自动评分的 mean、median、p25、p75、min、max，以及人工评分完成数、均值、中位数和分布。

复制整个报告目录（包括动作文件、资源和 `human_scores.json`）即可继续评审。正常增量评测和重新生成报告会保留评分文件；任务参数或动作内容发生变化时，对应旧评分不再计入，页面提示重新评分。`eval_checkpoint.py --overwrite` 会按原有行为清空整个输出目录，包括人工评分。
